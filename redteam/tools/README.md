Individual notes per offensive tool: what it is, when it's used in this lab's playbooks, and why it was chosen over alternatives — the same template style used for the blue-team tools in `docs/reference/`.

Individual doc files will be added here one at a time, same as the blue-team tool docs — each covering what it is, its role in this lab, why it was chosen, its limitations, and how it fits into the playbooks that use it.

## Why this is separate from `../setup/`

`../setup/` covers getting the attacker VM operational once. This folder covers ongoing usage notes for each tool — the kind of detail that grows as more playbooks are added and more of each tool's capability gets used.
